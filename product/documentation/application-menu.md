# Menu aplikacji

Powłoka buduje sekcję Moduły i podmenu Nowy z katalogu modułów zarówno w panelu startowym, jak i w otwieranych oknach modułów. Nieobsługiwane operacje są nieaktywne. Obsługa tworzenia nowego elementu jest udostępniana przez INewItemWindow; obecnie implementuje ją Notatnik.

DropDownMenu jest wspólnym komponentem. Wiersze mają co najmniej 28 jednostek wysokości, tekst 11 jednostek, a nieaktywne opcje szary kolor. Otwarcie menu nie wybiera ani nie podświetla domyślnej pozycji. Podmenu otwierają się obok pozycji oznaczonej strzałką.
